# x402

`frontend/src/domain/x402.ts` — the per-device agent protocol. Part of [[Domain]].

Manages per-device agent keypairs, loads/stores signing keys, and produces the authorization for tap-to-pay without owner interaction.

Connects: [[AgentRegistry]] (authorization) · [[PaymentEscrow]] (authorize/claim) via [[soroban.ts]] / [[StellarService]].
Drives [[Flow - Tap to Pay]] and [[Flow - Escrow Payment]].

## On-chain API (Week 2)

- `buildAgentPolicy({ maxAmountXlm, expiryDays })` → `{ maxAmountStroops, expiresAt }` (validated)
- `registerDeviceAndAgentOnChain({ walletSecret, deviceHashHex, agentPublicKey, policy })`
- `getAgentPolicy(deviceHash, source)` → `get_policy` decoded, `null` on AgentNotFound
- `fundEscrow` / `withdrawEscrow` / `getEscrowBalance` — see [[PaymentEscrow]]
- `unlinkDevice` — revoke agent → sweep escrow → revoke device (see [[Flow - Escrow Payment]])
- Errors: `DeviceOwnedByOtherWalletError`, `InsufficientFundsError`; user text via `domain/contractErrors.ts`
