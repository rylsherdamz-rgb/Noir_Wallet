Features

Built for zero-friction commerce.

Open contracts, self-custody and sub-cent fees — without asking anyone to change how they pay.

  • Zero-interaction payments

    Tap any RFID sticker, NFC card or wearable to pay. No unlock required.

  • x402 protocol

    The wallet is debited on the hardware tap — no app and no confirmation step.

  • Per-device agents

    Each card has its own agent wallet with an independent balance and daily spending limit.

  • Soroban smart contracts

    device_registry, agent_registry and payment_escrow map hardware to wallets.

  • Wallet-authorized registration

    Owners sign their own device registration via wallet.require_auth(). Full self-custody.

  • PDAX fiat bridge

    Optional PHP cash-out, so merchants settle in the currency they actually want.

  • Cross-platform

    One React Native Expo codebase for iOS and Android, with native NFC.

Security

Simple to use. Robust by design.

Lose a tag and revoke it instantly — its remaining balance returns to your main wallet automatically.

  • Hashed device identity

    Tag UIDs are SHA-256 hashed at the terminal. The raw UID is never stored or transmitted.

  • Terminal authentication

    Only whitelisted POS terminals can start a payment, via API keys and signed challenges.

  • Replay protection

    Every tap carries a signed nonce, with 500 ms anti-double-tap rate limiting per device.

  • Blast-radius limits

    Isolated agent wallets and daily limits mean a lost tag never exposes your main funds.

  • Encrypted key custody

    Fee-channel and agent keys are sealed with envelope encryption by a KMS-backed KeyManager.

Architecture

Hardware tap to on-chain settlement.

  1. 01

    Tag

    RFID or NFC card, sticker or wearable

  2. 02

    Terminal

    Phone or POS reads the tag and SHA-256 hashes its UID

  3. 03

    Soroban contracts

    device_registry
    Maps device hashes to Stellar wallet addresses
    agent_registry
    Authorizes an agent per device for tap-to-pay signing
    payment_escrow
    Pre-funded escrow — instant authorize, merchants claim in batch
  4. 04

    Stellar

    Consensus and settlement in seconds

  5. 05

    Payout

    Merchant batch claim, or PHP cash-out through PDAX

Contract methods and deployed testnet and mainnet IDs are in the project README.
